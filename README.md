# Min Bucketlist

## Om projektet
Min Bucketlist är en webbplats där användaren kan samla saker som den vill uppleva, platser som den vill besöka
och mål som den vill uppnå.
Projektet är en del av en skoluppgift där jag har utvecklat en dynamisk och responsiv webbplats
med hjälp av HTML, CSS, PHP och MySQL.

## Syfte
Syftet med projektet är att skapa en personlig bucketlist där användaren enkelt kan lägga till,
visa och ta bort aktiviteter. Projektet har gett mig möjlighet att arbeta med objektorienterad PHP, databashantering och versionshantering
med Git och GitHub.

## Funktioner
Webbplatsen innehåller följande funktioner:
- Visa en lista över sparade aktiviteter.
- Lägga till nya aktiviteter med namn, beskrivning och prioritet.
- Ta bort aktiviteter från listan.
- Validering av formulär så att alla fält fylls i.
- Lagring av aktiviteter i MySQL-databas.

## Tekniker
Följande tekniker och verktyg har använts:
- HTML- Webbplatsens struktur.
- CSS- Webbplatsens utseende.
- PHP- Webbplatsens funktionalitet.
- MySQL- Lagring av aktiviteter.
- PDO- Anslutning mellan PHP och databasen.
- Git- Versionshantering.
- GitHub- Lagring och publicering av källkoden.
- Laragon- Lokal webbserver och databasmiljö.
- Visual Studio Code- Utvecklingsmiljö.

## Databasstruktur
Databasen innehåller en tabell:
- id
- name
- description
- priority
- created_at
